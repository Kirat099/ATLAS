# ATLAS v1

A mobile-first, local-first personal fitness tracker.

## Run
No build step is required. Open `index.html` in a browser, or deploy the repository with GitHub Pages.

## Included
- Customizable home dashboard
- Quick Actions drawer
- Custom workout days and exercises
- Live workout logging
- Previous set targets
- PR detection
- Diet/macros logging
- Weight/body-fat check-ins
- Measurements
- Steps and streaks
- JSON export/import
- Local storage
- Settings and goal tracking

## GitHub Pages
Repository → Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.

ATLAS is intentionally local-first in v1. No account or backend is required.
